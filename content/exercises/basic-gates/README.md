# Gerbang logika dasar

Buat modul `gates` yang menghasilkan semua gerbang dua input sekaligus:

| Port     | Arah   | Lebar | Keterangan |
|----------|--------|-------|------------|
| `a`, `b` | input  | 1     | input |
| `y_and`  | output | 1     | a AND b |
| `y_or`   | output | 1     | a OR b |
| `y_xor`  | output | 1     | a XOR b |
| `y_nand` | output | 1     | NOT (a AND b) |
| `y_nor`  | output | 1     | NOT (a OR b) |
| `y_xnor` | output | 1     | NOT (a XOR b) |
| `y_not`  | output | 1     | NOT a |
