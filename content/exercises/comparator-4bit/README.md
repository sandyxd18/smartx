# Comparator 4-bit

Buat modul `cmp4` yang membandingkan dua bilangan 4-bit **tak bertanda**:

| Port     | Arah   | Lebar | Keterangan |
|----------|--------|-------|------------|
| `a`, `b` | input  | 4     | bilangan yang dibandingkan |
| `lt`     | output | 1     | 1 jika `a < b` |
| `eq`     | output | 1     | 1 jika `a == b` |
| `gt`     | output | 1     | 1 jika `a > b` |
